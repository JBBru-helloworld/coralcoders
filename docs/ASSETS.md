# Brand and photo assets

## Originals (local only)

Put the owner's original files here. This folder is gitignored: the files are large, and phone photos carry GPS location data in their EXIF metadata, so they must never be committed or published.

| File | Specification |
|---|---|
| `assets/originals/brand/logo.svg` | The coral mark. The current file is a Canva export that wraps an embedded raster, so it is treated as a raster. A true vector SVG would be better. |
| `assets/originals/tutor/joshua-bonham.jpg` | Portrait, at least 1200 px tall. |

`assets/originals/brand/logo_1.svg` (a pinker variant of the mark) is currently unused.

## Generated outputs (committed)

`pnpm assets` (run automatically by `pnpm dev` and `pnpm build`) rebuilds these from the originals with all metadata stripped. If the originals are missing, as on a CI host, the step is skipped and the committed outputs are used.

| Output | Use |
|---|---|
| `public/brand/logo-mark-96.webp`, `logo-mark-192.webp` | Header, mobile menu and footer mark (1x and 2x) |
| `public/brand/logo-mark-512.png` | schema.org `logo` |
| `src/assets/brand/logo-mark.png` | OG image renderer |
| `src/app/icon.png` (512), `apple-icon.png` (180, sand background), `favicon.ico` (32) | Favicons |
| `public/images/tutor/joshua-bonham-640.webp`, `-1280.webp` | Tutor photo (each under 150 KB) |

The coral hero images in `public/coral/` are generated by `scripts/build-coral.mts` at every build and are not committed.
