# Assets needed from the owner

Add these files at the exact paths below. Do not add placeholder, mock or stock images; components show a neutral CSS placeholder until the real file exists.

## Brand: `public/brand/`

| File | Required | Specification |
|---|---|---|
| `logo.svg` | Yes (preferred) | Full logo as SVG, transparent background. |
| `logo.png` | Only if there is no SVG | Full logo as PNG, at least 512 px wide, transparent background. |
| `logo-mark.svg` | Optional | The standalone icon or mark, if one exists. Used for the favicon and small placements. |

## Tutor photo: `public/images/tutor/`

| File | Specification |
|---|---|
| `joshua-bonham.jpg` | Portrait orientation, at least 1200 px tall, JPEG, under 400 KB. |
