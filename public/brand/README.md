# Brand assets

Add these files to this folder (`public/brand/`):

| File | Required | Specification |
|---|---|---|
| `logo.svg` | Yes (preferred) | Full logo as SVG, transparent background. |
| `logo.png` | Only if there is no SVG | Full logo as PNG, at least 512 px wide, transparent background. |
| `logo-mark.svg` | Optional | The standalone icon or mark, if one exists. Used for the favicon and small placements. |

Use these exact filenames. Do not add placeholder or mock logos here.
